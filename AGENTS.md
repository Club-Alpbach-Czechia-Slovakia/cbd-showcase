# Agent instructions

This repo is a hackathon showcase gallery (React + Vite + Tailwind). For any LLM/agent:

- **Add or update a website/project:** follow `skills/add-website/SKILL.md`.
- **Reuse the gallery in another (Lovable) app:** follow `skills/integrate-showcase/SKILL.md`.
- Always finish with `npm run validate && npm run build`, then commit and push to `main`: pushing auto-deploys to GitHub Pages (https://peterwolfframm.github.io/cbd-showcase/).
- Don't hand-edit `src/components/showcase/` for data changes; edit `src/data/projects.json`.
